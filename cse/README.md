# COLID CE NS 投稿协议（app.sprite3）

**适用于：** [https://github.com/ningqi24/COLID-CE-NS/issues](https://github.com/ningqi24/COLID-CE-NS/issues) 投稿渠道

---

## 一、投稿说明

1. 您通过上述 Issues 渠道提交的任何内容（包括但不限于代码、素材、建议、反馈等），均视为自愿向 **COLID CE NS** 项目投稿。
2. 投稿内容应为本项目相关的 **app.sprite3（即COLID CE NS.sb3作品中所谓的 `.cse` 应用）** 或其他可复用资源。

---

## 二、版权与署名

1. 您投稿的内容，其版权归您本人所有，但您需确保该内容不侵犯任何第三方权益。
2. 您同意授予本项目作者 **ningqi** 及 **COLID Studio** 非独占、永久、全球范围内、免版税的使用权，包括但不限于修改、合并、发布、分发该内容。
3. 投稿被采纳后，我们将在项目内或相关文档中标注您的贡献者身份（除非您要求匿名）。

---

## 三、合规要求

1. 投稿内容不得包含色情、暴力、血腥、政治敏感或其他违反中华人民共和国法律法规的元素。
2. 投稿内容不得恶意利用或放大 COLID OS / COLID CE NS 的已知 Bug。
3. 投稿内容须尊重 **COLID OS** 原创版权，不得删除或篡改原始署名信息。

---

## 四、处理方式

1. 项目维护者有权决定是否采纳、合并或拒绝您的投稿，无需另行解释。
2. 未被采纳的投稿，您可自行处置；已采纳的投稿将纳入项目版本，不再另行通知。
3. 若投稿存在争议，以 **COLID Studio** 生态部（高小圈）的最终裁定为准。

---

1. 投稿内容如引发任何法律纠纷，由投稿人自行承担全部责任。
2. 项目作者不对投稿内容的完整性、安全性或兼容性作任何担保。
